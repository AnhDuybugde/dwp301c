# Simple Interest Calculator

This project is a simple interest calculator that helps users calculate interest based on principal amount, annual interest rate, and time period.

## Features

- Accepts the principal amount
- Accepts the rate of interest
- Accepts the time period in years
- Calculates simple interest using the standard formula
- Displays the calculated interest clearly

## Formula

```text
Simple Interest = (Principal x Rate x Time) / 100
```

## Example

If the principal amount is `1000`, the interest rate is `5%`, and the time period is `2` years:

```text
Simple Interest = (1000 x 5 x 2) / 100
Simple Interest = 100
```

## Purpose

The purpose of this project is to demonstrate basic programming logic, user input handling, and calculation using a simple financial formula.
