# Paradise Nursery

Paradise Nursery is a plant shop application built with React. The project provides a landing page, company information, a plant product listing page, and a shopping cart experience.

## Project Name

Paradise Nursery

## Project Details

The application allows users to browse indoor and outdoor plants, add plants to a cart, update item quantities, remove items from the cart, and review the total cost before checkout.

## Main Files

- `App.jsx`: Landing page with the company name and Get Started button.
- `App.ess`: Styling file that implements the landing page background image.
- `AboutUs.jsx`: Company details for Paradise Nursery.
- `CartSlice.jsx`: Redux reducer logic for cart actions.
- `Productist.jsx`: Product listing page for the plant shop.
- `Cartltem.jsx`: Shopping cart page.
