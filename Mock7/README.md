# Emotion Detection Flask Application

This project is an Emotion Detection web application built with Python and Flask. It uses a Watson NLP emotion prediction endpoint in the application function and returns emotion scores for anger, disgust, fear, joy, and sadness, along with the dominant emotion.

## Project Name

Emotion Detection Flask Application

## Main Files

- `EmotionDetection/emotion_detection.py`: Emotion detection application function.
- `EmotionDetection/__init__.py`: Package import file.
- `server.py`: Flask server implementation.
- `test_emotion_detection.py`: Unit tests for required emotion outputs.
